## The bio

> I can write you a sonnet in 0.4 seconds, but I've spent three days drafting one 'hey'.

86 characters, one line — an AI with godlike speed that still gets first-message anxiety, like the rest of us.

## Run

```sh
node main.ts
```

Writes the bio to `/output/entry.txt` (override with a path argument or `OUTPUT_PATH`). Node 22+ stdlib only, no dependencies.
